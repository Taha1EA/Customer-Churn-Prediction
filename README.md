# Telecom Customer Churn Prediction

## Overview
This project predicts whether a telecom customer is likely to churn using Machine Learning. It includes exploratory data analysis, data preprocessing, model training, evaluation, and an interactive Streamlit application.

## Features
- Data preprocessing
- Feature engineering
- Logistic Regression model
- Customer churn prediction
- Interactive Streamlit dashboard
- Business insights and visualizations

## Dataset
IBM Telco Customer Churn Dataset

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Matplotlib
- Plotly

## Model
- Logistic Regression

## Metrics
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
